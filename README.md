SWYNEX Daily Task Manager

Project Overview

SWYNEX Daily Task Manager is a simple and responsive web application designed to help users organise daily activities, manage tasks, and track productivity.

Features

- Home dashboard with task summary
- Create tasks with due dates and priority levels
- View all tasks
- View individual task details
- Mark tasks as completed or undo completion
- Save tasks in browser local storage
- Profile page with app information

Technologies Used

- HTML
- CSS
- JavaScript
- Browser Local Storage
